# VaultSCAN

**A lightweight, open-source gold tracker for World of Warcraft Retail.**

VaultSCAN is a World of Warcraft addon designed to help players track their gold across multiple characters and realms, providing a simple way to monitor their wealth throughout Azeroth.

Created by **SCAN**, VaultSCAN aims to make managing your characters' wealth easy, organized, and accessible.

## Planned Features

- Track gold across multiple characters and realms.
- Automatically save character wealth between sessions.
- Update gold balances as players earn or spend money.
- Display character and realm information.
- Provide a clean, lightweight interface for viewing accumulated wealth.

## Development Status

🚧 **Early Development — v0.1.0**

VaultSCAN is currently in active development.

**Currently implemented:**
- Successful addon initialization in World of Warcraft Retail.
- Automatic detection of the current character's name and realm.
- Retrieval and formatting of the current character's gold balance.

**Coming next:** Persistent character wealth tracking using World of Warcraft's SavedVariables system.

## Installation

1. Download or clone this repository.
2. Place the `VaultSCAN` folder in your World of Warcraft Retail addon directory:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Ensure `VaultSCAN.toc` and `VaultSCAN.lua` are directly inside the `VaultSCAN` folder.
4. Launch World of Warcraft and enable **VaultSCAN** from the AddOns menu.
