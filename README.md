# AltVault

**A lightweight, open-source character wealth tracker for World of Warcraft Retail.**

AltVault is a World of Warcraft addon designed to help players track their gold across multiple characters, providing a simple way to monitor their wealth throughout Azeroth.

## Planned Features

- Track gold across multiple characters.
- Automatically save character wealth between sessions.
- Display character and realm information.
- Provide a clean, lightweight interface for viewing your gold.

## Development Status

🚧 **Early Development — v0.1.0**

AltVault is currently in its initial development phase. The addon loads successfully in World of Warcraft, with core wealth-tracking functionality coming next.

## Installation

1. Download or clone this repository.
2. Place the `AltVault` folder inside your World of Warcraft Retail addon directory:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Launch World of Warcraft and enable **AltVault** from the AddOns menu.
