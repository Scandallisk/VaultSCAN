# VaultSCAN Forever 1.0.0

VaultSCAN comes to World of Warcraft Forever with character-only wealth tracking, exact gold/silver/copper displays and support for Forever's first names and surnames.

Download **VaultSCAN-Forever-1.0.0.zip** and install its `VaultSCAN` folder under `_forever_/Interface/AddOns`. Use the adjacent SHA256 file to verify the ZIP. The automated GitHub source archives are repository snapshots, not the install package.

Open `/vaultscan` or click the minimap icon. Log into each character once with the addon enabled to build your roster. Account totals use the latest saved balances of those characters; offline balances are not live. No bank holdings are included.

The release includes a compact sortable roster, current/account money totals, played time, item-level history and daily combined-character money observations. The first observation each day is preserved, so current totals may differ from the latest graph point.

Compatible target: Forever 1.60.1, interface 16001. Tested by the owner on 1.60.1.70938 for character retention, names, money presentation, totals and layout. Automated Lua syntax and mocked logic checks passed. Live multi-day rollover, long-term retention and clean CurseForge installation have not yet been verified.

Retail VaultSCAN is a separate download and retains its own records and release history. This release does not update Retail.
